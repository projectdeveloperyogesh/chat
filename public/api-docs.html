⚡ Yogesh Chat REST API v1

Connect programmatically from external applications, scripts, cURL, Python, or Webhooks. Supports full AI multimodal capabilities including document Q&A and voice audio transcription.

Base Server URL: http://localhost:3005
GET /api/v1/status

Check Server Health & Available AI Models

Retrieves system health, active user count, total AI sessions, and available Gemini / Claude / GPT models.

curl -s http://localhost:3005/api/v1/status
POST /api/v1/upload

Upload Documents & Audio/Video Files

Upload raw PDF, DOCX, TXT, images, voice recordings (.wav, .webm), or videos via Multipart FormData.

curl -X POST http://localhost:3005/api/v1/upload \
  -F "files=@/path/to/voice_recording.wav" \
  -F "files=@/path/to/document.pdf"
POST /api/v1/ai/chat

Send AI Prompt with Attached Docs / Voice Audio

Pass text prompts and attached file objects (`files: [...]`) to Gemini 3.6 Flash / Claude / GPT models with multi-turn session memory.

curl -X POST http://localhost:3005/api/v1/ai/chat \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Transcribe this audio recording and list action items",
    "model": "Gemini 3.6 Flash (High)",
    "files": [{ "filename": "178617-voice_recording.wav", "originalname": "voice_recording.wav" }]
  }'
GET /api/v1/ai/sessions

List AI Conversation Sessions

Fetches all multi-turn AI session threads for a specific user.

curl -s "http://localhost:3005/api/v1/ai/sessions?username=Yogesh"
GET /api/v1/ai/sessions/:id

Get AI Session Transcript & Messages

Retrieves the complete message history and multi-turn transcript of a single AI session.

curl -s http://localhost:3005/api/v1/ai/sessions/session-1786171142081-623
POST /api/v1/ai/sessions

Create New AI Session Thread

Programmatically starts a new AI conversation thread.

curl -X POST http://localhost:3005/api/v1/ai/sessions \
  -H "Content-Type: application/json" \
  -d '{"username": "Yogesh", "title": "Data Analysis Project"}'
DELETE /api/v1/ai/sessions/:id

Delete Single AI Session Thread

Deletes an AI session thread from SQLite and unlinks associated attached files from disk.

curl -X DELETE http://localhost:3005/api/v1/ai/sessions/session-1786171142081-623
DELETE /api/v1/ai/sessions

Delete ALL AI Sessions for User

Clears all AI threads belonging to a user.

curl -X DELETE "http://localhost:3005/api/v1/ai/sessions?username=Yogesh"
POST /api/v1/messages

Broadcast Text Message to Global Lounge

Posts a live text message to the Global Lounge chat room via WebSockets.

curl -X POST http://localhost:3005/api/v1/messages \
  -H "Content-Type: application/json" \
  -d '{"username": "Build Bot", "text": "Deployment complete successfully!"}'
POST /api/v1/files

Broadcast Shared Files to Global Lounge

Shares uploaded file objects with an optional caption in the Global Lounge.

curl -X POST http://localhost:3005/api/v1/files \
  -H "Content-Type: application/json" \
  -d '{
    "username": "System Bot",
    "caption": "Project Release v1.0 Assets",
    "files": [{ "filename": "178617-release.zip", "originalName": "release.zip", "size": 1048576, "category": "archive", "url": "/uploads/178617-release.zip" }]
  }'
GET /api/v1/messages

Retrieve Global Lounge Chat History

Fetches all Global Lounge messages stored in the SQLite database.

curl -s http://localhost:3005/api/v1/messages
DELETE /api/v1/messages/:id

Delete Single Message & Storage File

Deletes a chat message or shared file from SQLite and removes associated files from server disk storage.

curl -X DELETE http://localhost:3005/api/v1/messages/msg-1786171142081-123
DELETE /api/v1/messages

Delete ALL Global Lounge Messages

Clears all messages in the Global Lounge chat room and removes files from disk.

curl -X DELETE http://localhost:3005/api/v1/messages
DELETE /api/v1/chats/all

Clear ALL Chats, AI Sessions, & Disk Files

Completely purges all database tables (Global Lounge + AI Threads) and deletes all uploaded files from disk.

curl -X DELETE http://localhost:3005/api/v1/chats/all
