Yogesh Chat REST API Reference

Connect programmatically from Python, cURL, Node.js, or external systems

⚡ Base URL & Health Endpoint

http://localhost:3000/api/v1/status

🔌 Available REST Endpoints

POST /api/v1/ai/chat

Send AI prompt with multi-turn session memory, model selection, & attached documents/voice audio files.

POST /api/v1/upload

Upload raw documents, PDF, DOCX, images, audio, or video files to server storage.

GET /api/v1/ai/sessions

Retrieve AI conversation session threads list.

POST /api/v1/ai/sessions

Create a new AI conversation session thread.

DELETE /api/v1/ai/sessions/:id

Delete an AI conversation session thread.

POST /api/v1/messages

Broadcast a text message live to the Global Lounge chat room via WebSockets.

POST /api/v1/files

Broadcast shared files with optional caption live to the Global Lounge chat room.

GET /api/v1/messages

Retrieve Global Lounge chat messages history.

DELETE /api/v1/messages/:id

Delete a chat message or uploaded file from server & disk storage.

GET /api/v1/status

Check server health, active users count, and available AI models.

💻 Code Examples

cURL Example (AI Chat)

curl -X POST http://localhost:3000/api/v1/ai/chat \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Explain quantum physics", "model": "Gemini 3.6 Flash (High)"}'

Python Example

import requests

res = requests.post("http://localhost:3000/api/v1/ai/chat", json={
    "prompt": "Write a Python script",
    "model": "Gemini 3.6 Flash (High)"
})
print(res.json()["reply"])
